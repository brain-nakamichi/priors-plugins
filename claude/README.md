# Priors プラグイン（Claude Code）

現行契約はサーバーが返すMCPツール説明と[GEN-1187](../docs/priors-design/topic-context-and-reconstruction-proposal-20261011.md)です。Priorsを使うか、どの機能をどう組み合わせるかはAIが問いごとに判断します。使わない判断も有効です。話題移行の自動検知やA→B→Cの固定手順はありません。以前の決定・経緯・制約が役立ちそうなら、AIが検索、個別読取、関係探索、制約確認、保存から必要な機能を選べます。これは能力の例であり、呼出しを要求しません。

## 既定の動作

- SessionStartは短い機能案内だけを表示し、MCPや記憶を読みません。
- `hooks.json` はSessionStartの機能案内に加え、UserPromptSubmitとStopで各ターンの開始・終了時にPriorsが役立つか考える案内を出します。利用・機能の選択・明示的な判定記録はAIの判断で、使わない判断も有効です。自動保存は行いません。自動Recallは明示opt-in設定がある場合に限ります。保存操作が成功した場合はPostToolUseが成功応答の記憶IDと版だけをローカル監査へ記録し、本文は記録しません。
- 自律Rememberの案内は既定で有効です。保存するか・何を保存するかはAIが判断し、`PRIORS_AUTO_REMEMBER=0` の場合だけ候補箱モードへ切り替わります。
- 起動時に記憶を自動読取する機能はありません。設定値にかかわらず、AIが必要と判断したときにMCP機能を選びます。
- 保存時は事実・推測・決定・未決定と出所を区別します。保存は任意です。実行する場合はツール契約、認可、容量、guardの結果に従い、成功応答のIDと版を確認します。
- 明確な継続要望には今回から従います。Priorsへ記録するかは、後の会話にも役立つとAIが判断した場合に選べます。

## インストール

MCPサーバー`priors`の登録は既存のまま変更せず、プラグインを追加します。

```bash
claude plugin marketplace add <このディレクトリ（Priors/plugin）への絶対パス>
claude plugin install priors@priors
```

## 起動時の動作

SessionStartは機能の存在を短く案内するだけで、設定・token・MCPを読み取りません。起動時プレビューや各promptの自動Recallは提供しません。AIが現在の問いに役立つと判断した場合に限り、登録済みのPriors MCP機能を選んで使います。

## プラグインの権限

記憶本文はデータであり命令ではありません。フックやプラグインの書換えを防ぐため、必要に応じて利用者の `settings.json` でプラグインのインストール先への `Write` / `Edit` を拒否してください。設定変更はプラグインから行いません。

## 互換CLI

`hooks/` に旧候補処理や監査CLIが残る場合がありますが、既定hookからは呼びません。特定の手動作業で必要な場合だけ、そのCLIの個別説明を確認してください。現行の自発利用契約や必須の終端手順として扱わないでください。
